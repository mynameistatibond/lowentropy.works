# 🐍 Quiz Snake

A knowledge-testing snake game embedded in [lowentropy.works](https://lowentropy.works). The player controls a snake that eats correct answers to quiz questions. Ships with 100 questions on the EU AI Act, but also supports **custom quiz packs generated by an LLM** from any source material.

**Live:** [lowentropy.works/pages/play-me/](https://lowentropy.works/pages/play-me/)

---

## 🎮 Game Mechanics

### Core Loop
1. A quiz question appears in the HUD bar at the top
2. Two answer tokens (**A** and **B**) spawn at random positions on the grid
3. Steer the snake to eat the **correct** answer
4. Correct → score +1, snake grows by 1 segment
5. Wrong → lose a life (❤️), question resets
6. Hit a wall or yourself → lose a life, snake resets to center

### Progression

| Level | Speed (ms/tick) | Questions to Clear |
|-------|----------------|--------------------|
| 1     | 260            | 10                 |
| 2     | 250            | 10                 |
| 3     | 240            | 10                 |
| 4     | 230            | 10                 |
| 5     | 220            | 10                 |
| 6     | 200            | 10                 |
| 7     | 190            | 10                 |
| 8     | 180            | 10                 |
| 9     | 170            | 10                 |
| 10    | 145            | 10                 |

- **10 levels × 10 correct answers = 100 points for full victory**
- Snake speed increases with each level (260ms → 145ms per tick)
- Snake length carries over between levels (longer snake = harder to navigate)
- Each level has a themed EU AI Act completion message (e.g., "You are now Mildly Compliant")

### Lives & Difficulty
- **5 lives** (♥♥♥♥♥) at game start
- Lives are lost by: hitting walls, eating yourself, choosing wrong answers
- No extra lives are earned during play
- Answer tokens spawn with minimum distance from the snake head (4 cells) and from each other (6 cells)

### Controls

| Action | Keys |
|--------|------|
| Move   | Arrow keys / WASD |
| Pause  | Space |
| Start  | Space / Enter / Tap |

Touch controls are supported: swipe direction detection on the canvas.

## 📦 Question Pack Format

Both the default pack and custom packs use the same JSON format:

```json
[
  {
    "prompt": "When did the AI Act enter into force?",
    "options": ["1 August 2024", "12 July 2024"],
    "correctIndex": 0
  }
]
```

| Field | Type | Description |
|-------|------|-------------|
| `prompt` | string | The question text displayed in the HUD |
| `options` | string[2] | Exactly 2 answer options |
| `correctIndex` | 0 \| 1 | Index of the correct answer in `options` |

**Note:** The game randomly swaps A/B positions at runtime, so the `correctIndex` in the JSON doesn't determine which side of the board the correct answer appears on.

### Question Recycling
If a pack has fewer than 100 questions, the game automatically reshuffles and recycles them when it runs out. This means a 45-question pack can still fill all 10 levels — later levels will include shuffled repeats from earlier.

## 🧠 Custom Pack Creation (LLM Integration)

### User Flow

```
┌─────────────────┐     ┌──────────────────┐     ┌────────────┐     ┌──────────┐
│   Mode Select   │────→│   Source Input    │────→│  Loading   │────→│  Review  │
│  Default / New  │     │  Paste text here  │     │  Spinner   │     │  5 Q's   │
└─────────────────┘     └──────────────────┘     └────────────┘     └──────────┘
        │                                                                │
        │ "Play AI EU Act"                                    "Start Snake 🐍"
        ▼                                                                ▼
   ┌──────────┐                                                  ┌──────────┐
   │  Game    │                                                  │  Game    │
   │ (default)│                                                  │ (custom) │
   └──────────┘                                                  └──────────┘
```

### How It Works

1. **User pastes source text** (lecture notes, articles, policy docs, etc.)
2. **Frontend** (`pack-creator.js`) sends a POST to the fraud-detector backend
3. **Backend** (`app.py → /generate_quiz_pack`) estimates optimal question count from text metrics, then calls the LLM
4. **LLM** (Groq, `llama-3.3-70b-versatile`) generates questions in the correct JSON format
5. **Backend** validates every question (correct structure, 2 options, valid correctIndex)
6. **Frontend** shows a preview of 5 questions for review
7. **User clicks "Start Snake"** → questions injected into `window.selectedQuestionPack`
8. **Game engine** reads from that variable instead of loading `quiz-bank.json`

### Question Count Estimation

Rather than always requesting 100 questions (which causes hallucination on short texts), the backend estimates the optimal count:

| Source Length | Density | Estimated Questions |
|---|---|---|
| ~200 chars (1 paragraph) | Thin | 10-15 |
| ~1,000 chars (half page) | Light | 20-30 |
| ~3,000 chars (1-2 pages) | Medium | 40-60 |
| ~6,000+ chars (3+ pages) | Rich | 80-100 |

Metrics used: sentence count (primary), word count (secondary), unique word ratio (density penalty for repetitive text). See `estimate_question_count()` in `app.py`.

### LLM Backend

The quiz pack generation reuses the **same Groq LLM infrastructure** as the fraud detection project:

```
pack-creator.js                    fraud-detector/app.py
────────────────                   ──────────────────────
POST /generate_quiz_pack ──────→  get_llm_config()
                                       │
                                       ├─ GROQ_API_KEY from .env
                                       ├─ robust_api_call() with retry logic
                                       ├─ Groq API (llama-3.3-70b-versatile)
                                       │
                                  ◄── { questions, meta }
```

Three use cases share the same key and infrastructure:

| # | Use Case | Where |
|---|----------|-------|
| 1 | Fraud risk narratives | `/predict?llm_explain=true` |
| 2 | Batch triage reasoning | `/submit_batch` → `triage.py` |
| 3 | **Quiz pack generation** | `/generate_quiz_pack` → `app.py` |

### Fallback (No Backend)

If the fraud-detector server isn't running, `pack-creator.js` falls back to a **client-side simulation**:
- Extracts sentences from the source text
- Wraps them in true/false question templates
- Shows a warning banner: "Demo mode — using simulated questions"
- Game still works — just lower quality questions

## 🚀 Running Locally

### Static site only (default pack + simulation fallback)

```bash
cd lowentropy.works
python3 -m http.server 3000
# Open http://localhost:3000/pages/play-me/
```

### With LLM-powered custom packs

```bash
# Terminal 1: Static site
cd lowentropy.works
python3 -m http.server 3000

# Terminal 2: Fraud-detector backend (provides LLM endpoint)
cd fraud-detector
source venv/bin/activate
uvicorn app:app --reload --port 8000
# Requires GROQ_API_KEY in fraud-detector/.env
```

## 🎨 Visual Design

- **Typography:** Shippori Mincho B1 (serif) — matches the lowentropy.works site

- **Snake:** Olive green body with darker outline, pointed nose, round eyes
- **Answer tokens:** Bordered circles, correct answer highlighted in purple on review

  - Score pop (CSS scale + fade)
  - Heart explosion particles (DOM-based, physics simulation)
  - Green sparkle particles on correct answer
  - Overlay fade-in transitions
- **Responsive:** Grid dynamically resizes based on container width (32px → 18px cells)

## 📝 Default Question Pack

The shipped `quiz-bank.json` contains **100 questions** covering the EU AI Act:
- Publication dates and timeline
- Risk classification system (unacceptable, high, limited, minimal)
- Prohibited AI practices
- High-risk AI system requirements (Annex III)
- General-Purpose AI (GPAI) obligations
- Governance structure (AI Office, AI Board)
- Conformity assessment procedures
- Sanctions and penalties
- Fundamental rights impact assessments
- Provider vs. deployer responsibilities

The level completion messages are themed around EU compliance humor ("You are now Mildly Compliant", "Annex III is no longer staring at you menacingly", etc.).
